# 活动范围与像素立体胶水覆盖

## 已确认的需求

用户选择按介质区分活动半径：胶水约 1.2 格、蜂蜜 1 格、焦油 0.8 格、黏液 1 格、黏稠泥潭 0.6 格、粘鼠板 0.7 格。胶水覆盖采用明显的逐像素凸起，颜色保持白色半透明。

## 实现方案

- 增加服务端各介质的完整黏力活动半径配置，调整黏丝松弛长度，让普通走动能接近范围边缘；挣扎继续扩大范围、削弱回拉并允许挣断。短跳、救援、下陷、FOV 和飞行豁免保持现有机制。
- 断裂距离至少留出活动半径加 0.4 格的脚部转动和短跳余量，兼容旧配置中较短的泥潭断裂距离，避免转身提前断开。
- 复用现有胶水透明贴图与十级覆盖蒙版；按蒙版生成独立的像素厚度网格，凸起厚度有细微变化，外侧与侧壁使用正常光照。提高可读性但仍可看见衣服和皮肤。浅层仅覆盖腿脚，深层逐步覆盖身体，水洗和残留消退继续控制可见度。
- 第三人称及第一人称手臂共用生成规则；宽臂和细臂正确使用各自尺寸。模型跟随玩家部位姿势，不修改皮肤、3D Skin Layers 的网格或原版模型。
- 3D Skin Layers 为可选模组。读取其公开配置中的体素尺寸，为胶膜留出外层间距；未安装时直接使用原版外层间距。增加默认开启的客户端“立体胶水覆盖”开关。资源重载后清除网格缓存。
- 本模组自己实现几何生成，不复制或捆绑 3D Skin Layers 源码/JAR。兼容测试使用工作目录内的官方 1.21.11 NeoForge 1.11.3 JAR。

## 验证

1. 纯 Java 回归：各介质默认半径、弱化、松弛力、断裂余量，以及 UV 蒙版映射、像素网格范围、宽细臂与覆盖等级。
2. 正常构建、资源检查及服务端回归，确保客户端可选兼容代码不污染专用服务器。
3. 安装实际产物到工作目录内的隔离游戏实例，以非飞行状态验证走动/跑跳/F 脱困/FOV。
4. 分别不安装及安装 3D Skin Layers 运行外观检查，验证其实际注入网格；只保存必要的对比截图并直接查看，检查外层遮挡、半透明可见性、姿势和臂宽。

所有修改和测试都在当前工作目录内进行；桌面导出目录与用户日常游戏实例不改动。
