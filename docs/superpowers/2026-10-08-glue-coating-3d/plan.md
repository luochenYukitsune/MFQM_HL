# 实施与验证计划

设计确认后按以下顺序执行；当前任务由主代理完成，以控制子代理开销。

1. 先为完整黏力半径、接近边缘时的回拉和转身/短跳断裂余量增加失败测试；实现统一的活动半径规则、服务端配置与本地预测使用相同计算。
2. 为蒙版取样和面网格生成增加失败测试；实现独立、可缓存的逐像素凸起和边缘侧壁，不修改 PNG 文件。几何跟随原玩家模型各部位的实际姿势。
3. 读取可选 3D Skin Layers 的公开体素大小配置，适配默认和放大尺寸；第一人称使用其单独的像素比例。异常时回退并仅记录一次提示。
4. 增加中文配置文案与 0.6.4-dev 更新说明，检查资源重载、宽/细臂、覆盖开关及水洗残留。
5. 构建、资源检查、服务端回归；安装实际 JAR 到隔离客户端，分别运行无附加模组及 3D Skin Layers 1.11.3 的验证。外观截图限于必要的宽/细臂、浅/深覆盖和第一人称对比。
6. 检查最终差异和实际测试证据，修复发现的问题，记录验证范围及局限，提交本地 Git 并交付新 JAR。

兼容模组来自[作者的 Modrinth 项目](https://modrinth.com/mod/3dskinlayers)，测试版本为 1.11.3，Minecraft 1.21.11 / NeoForge；官方 SHA-512 已核对。外部 JAR 仅存放在被 Git 忽略的 run/compat，发布产物不包含它。
