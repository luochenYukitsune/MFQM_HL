# 弹性受困与粘鼠板修正

用户确认：角色能实际小范围挪动、跑动和短跳，黏丝绷紧后拉住；挣扎削弱后脱困。原有“全程取消跳跃、几乎零位移”不再符合需求。FOV 不因模组黏度变化，保留用户设置及原版行为。

生产实现将黏连的固定起点、活动范围和黏力同步给客户端；范围内允许实际输入位移，边缘由黏丝拉力与碰撞安全的范围限制共同约束。短跳是有限、一次按下触发的弧线，持续按住不会连续上浮；挣扎下陷、深池危险、真实救援及受击窗口保留。挣扎扩大活动范围，充分削弱后能挣断；切换介质、换维度、移除胶层会清理状态。

用户确认测试的是创造栏直接取出的普通板，现实现为空底板。继续保留生存制作底板、右键补胶、涂层消耗与回收；创造栏将已涂胶板与空板相邻展示，分别命名和说明涂层。修复胶面近乎共面的透明层模型，使用现有纹理及稳定几何/UV，不另生成图片。

验证重点：真实行走/跑跳产生位移但不会越界；按住跳跃不飞升；FOV 与用户选项不变；创造栏取出的涂胶板直接放下即可受困，空板明确提示；模型/渲染层检查、实际服务端和安装 JAR 回归。主要由主代理实现和复核，不增加开发代理。
