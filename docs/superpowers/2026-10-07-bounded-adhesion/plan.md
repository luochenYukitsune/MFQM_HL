# 实施与验证

1. 在 `AdhesiveMotion` 与纯 Java测试中先验证范围投影、有限短跳、持续按住及重新按下；旧行为不能满足实际短跳验收。
2. `SinkingState` 同步黏连起点/范围/介质及强度；`AdhesionController` 维护生命周期、扩展活动范围和板释放；`QuicksandPhysics` 在实际 move 前应用范围，保留真实外力。
3. 删除模组移动速度属性拖拽，改用实际运动阻尼，消除属性驱动的 FOV 变化；旧存量属性仍清理。客户端场景工具不修改 FOV。
4. `StickyBoardItem` 按涂层命名和提示，创造栏相邻列出两种；模型使胶面与木面具有稳定间距和明确边框，正确渲染手持/地面。
5. 修订此前完全禁跳的测试为真实有限短跳和范围验收，新增实际涂胶板/空板对照与 FOV 检查；构建、纯规则、独立服务器和最终安装 JAR 测试。
6. 主代理复核、记录日志和准确边界，提交本地 Git，提供新开发 JAR；不修改桌面副本。
