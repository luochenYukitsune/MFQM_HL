# 0.6.3-dev：FOV、有限走跳与粘鼠板

针对用户确认的“实际小范围挪动、跑动和短跳，黏丝绷紧后拉住；挣扎削弱后脱困”修正。目标为 Minecraft 1.21.11 / NeoForge 21.11.45 / Java 21。所有开发及隔离运行均在当前工作目录内；桌面导出副本和启动器正式实例未修改。

## 结果与实现

- 创造栏相邻显示 **粘鼠板（已涂胶）**、**粘鼠板底板（未涂胶）**，总数保持 165 个可见项、180 个注册物品。涂胶版通过 `BLOCK_STATE` 带 7 格胶层，使用普通 `BlockItem` 放置后直接生效；空板保留制作、补胶和重复回收用途。
- 删除模组黏度及粘鼠板的 `MOVEMENT_SPEED` 属性缩放，用实际运动阻尼和范围约束完成束缚，避免原版 FOV 随速度属性变化。旧残留属性会清理；用户视角设置及原版疾跑、拉弓效果保留。
- 固定黏连起点、介质和强度同步到客户端。在原版碰撞移动前投影水平步长到圆形活动范围；挣扎降低强度并扩大范围，救援与真实受击窗口保留。不会每 tick 传送角色来制造受困效果。
- 有限短跳按下触发，以角色模拟计时而不是会被网络校正的世界时间计时。胶水、焦油等介质在短跳弧线内保留新增挣扎代价，结束后恢复原有下陷；按住不会连续上浮。
- 粘鼠板胶面与木面保持稳定间距，缩入四边留出木框，使用明确 UV、方块父模型和 cutout 渲染。沿用已有 PNG，未生成新贴图。
- 耗尽胶层或移除介质的连接在实际运动前失效；重新涂胶和换板清理旧起点、创建新受困过程，同时保持专用挣扎冷却。
- 附件同步格式随新增起点字段更新，网络协议为 `5`；客户端和服务端均需使用 0.6.3-dev。

## 验证

构建成功；纯 Java 验证包括运动 35 组与 35 个边界样本、黏连 241 项、范围/短跳 69 项、挣扎 739 项、姿态 378 项。启动器 19 项测试通过；JAR 元数据/资源与移植资源校验为零错误。

独立服务器通过 71 组玩法及 `/reload` 检查。真实生物使用原版 `aiStep`、`JumpControl` 与 `travel`；手动测试夹具按 `ServerLevel.tickNonPassenger` 相同方式推进 `tickCount`，连续推进自救期间每一个模拟 tick，短跳落地后再测普通跳跃。首 tick 空板释放、重新涂胶、换板、留靴及换维度均通过。

实际 JAR 已通过 23 个非飞行介质场景，包括浅池、深池、薄流体、生存与地面创造、真实 W 和持续跳跃；胶水/焦油/蜂蜜峰值短跳约 0.21～0.22 格，最终回落。静止 FOV 均为普通视角倍率 `1.0`。

初次完整运行在普通走路的异步终点采样上失败：客户端仍有普通惯性位移，测试将它与较早服务器采样比较。修正为 W 输入 60 tick、自然停稳 8 tick 后采样，未改玩法实现。最终 JAR 仅两个 opt-in 测试夹具及其中匿名类不同，全部玩法和资源字节与通过 23 场景的 JAR 相同，见 [逐项 JAR 对照](jar-comparison.json)。使用 `--actions-only --board-visual` 定向重测该动作组及粘鼠板。

动作组已通过：5 次真实 F 使悬空胶水两端都下陷 0.05 格，静止无重放；一次救援抬高约 0.43 格并正常结束；离开介质后走路约 12.95 格且两端终点一致；一次真实攻击击退抬高约 0.78 格，外力窗口到期后自然落地。

粘鼠板真实放置与空板对照、FOV、走动约 0.34 格、短跳 0.26 格及按住后的两端回落均通过。走/跑/跳的最大水平离起点距离约 0.37 格，全程在随黏力变化的范围内。此前移动和跳跃也计入挣扎，本次再按 33 次真实 F 后解除束缚，随后正常走出约 12 格。测试始终关闭飞行。

唯一必要的 [模型截图](mfqm-board-fixed.png) 已由主代理目视检查：左侧为空木底板，右侧为已涂胶板；木边框、薄侧面和白色胶面分明，没有缺失贴图方格或近乎共面重叠。截图来自实际游戏，未生成或重绘 PNG 材质。
