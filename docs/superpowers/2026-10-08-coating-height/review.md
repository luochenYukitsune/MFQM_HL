# 修正审查

由主代理检查需求符合性、生产代码和测试证据，本次不新增子代理。

旧蒙版第三级已有躯干区域：128×64 的泥土图中有 444 个躯干区域非透明像素，胶水图为 280 个。旧 `ceil(depth/height*10)` 又把 0.65/1.8 算成第四级。新的前三级在实际身体网格检查中均没有头、躯干或手臂像素。

生产改动只涉及覆盖等级的取整与参考高度、五类贴图的选择、胶膜透明度和厚度。活动半径、拉力、F 输入、跳跃、救援、留靴、网络字段和注册身份保持原有实现。服务器和客户端都要使用 0.6.5-dev，才能使用同一等级解释和新贴图。

UV 处理显式区分侧面、顶面和底面，保留最高级材质的原有细节与孔洞，旧 PNG 的验证哈希全部通过。生成器校验输出范围、五类十级递增、实际像素高度上限、源图不可变以及透明度。资源来自本项目现有贴图；无第三方实现复制、AI 生成或额外运行时依赖。

实际宽/细臂网格、第一人称、平面开关、资源重载与 3D Skin Layers 间距验证通过。直接查看三张游戏截图，确认胶膜更淡、第三级腿部覆盖时上半身干净、真实第一人称手臂仍有薄透明凸起。截图头像仅用于视觉，物理覆盖用服务器 FakePlayer 的实际接触和附件更新另外验证。

无阻塞问题。限制：十级取整使新残留的高度以约十分之一身高为一档，极浅接触至少保留一级脚踝效果。共享宽/细臂 UV 的顶底面有一列重合，采取保守裁切，细臂掌底一列会晚到肩部高度才出现；这避免涂到尚未浸入的宽臂肩面。仍保留历史深陷残留，不把走到浅处当作自动清洗。非标准玩家模型、爬行/游泳姿势的逐世界像素水线和其他着色模组尚未专门验收。

合载中仍出现官方 3D Skin Layers 1.11.3 及内嵌库原有的资源包描述字段错误。原始错误保留在日志；仅其精确已知格式错误允许继续，其余加载与图形错误仍会中止测试。
