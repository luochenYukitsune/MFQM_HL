# 胶膜浓度与浸入覆盖修正

用户本次反馈授权修正已批准方案中的两项表现：胶膜过浓、腿部浸入时上半身提前变脏。继续使用十级覆盖和原有持久残留、水洗机制，不改变运动、挣扎或黏连参数。

原来的第三级蒙版已有躯干像素，而物理层把浸入比例线性向上取整；这两个定义并不对应。新运行时蒙版以已有最高级材质为来源，按原版玩家 32 像素高的 UV 布局，从脚向头裁切；等级按浸入比例向下取整，避免提前绘制下一高度。极浅接触仍至少保留一级脚踝残留。使用站立身体高度作为稳定参考，避免潜行改变碰撞箱后覆盖突然跳级。

为保留旧资源及其验证记录，生成五组新的高度蒙版，旧 PNG 不改动。胶水新蒙版的 alpha 缩为原来的 55%，3D 网格保留该透明度，不再额外增白；像素凸起厚度减半。平面回退与第一人称同步变淡。保留 3D Skin Layers 间距适配。
