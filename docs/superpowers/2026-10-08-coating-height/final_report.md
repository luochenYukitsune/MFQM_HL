# 0.6.5-dev 胶膜浓度与身体覆盖高度验收

已完成两项修正：胶水身体覆盖过浓、腿部浸入却提前绘制上半身污渍。仅修改当前工作目录，没有改动桌面导出副本或日常游戏实例。本次未新增子代理。

## 修正

旧图第三级已经有躯干像素，旧等级计算还向上取整；现在五种身体材质各有十张按皮肤 UV 实际高度裁切的蒙版，等级从脚向头递增并向下取整。新鲜腿部浸入保持躯干、手臂和头部干净；潜行采用站立身体高度作稳定参考，避免缩短碰撞箱导致突然跳级。

胶水新蒙版 alpha 为原材质的 55%，立体网格直接保留蒙版透明度，取消原来的额外增白；像素凸起从 0.24～0.48 模型像素减到 0.12～0.24。近处立体效果、第一人称和平面回退同步变淡。复用最高级现有材质，新增 50 张必要的运行时高度蒙版；旧 PNG 和原有素材保持哈希不变，没有生成 AI 图片。黏度、活动距离、F、有限短跳与救援仍采用原有实现。

深陷留下的历史残留仍会保留；返回浅处不会自动清洗，上半身的旧残留需通过原有消退或水洗机制清理。测试当前高度时可以先清洗角色，避免把已有残留当作新接触。

## 边界

十级覆盖仍是离散档位，极浅接触保留一级脚踝效果。共享宽/细臂 UV 的顶底面一列重合采用保守裁切，细臂掌底该列会到肩部高度才出现，以避免宽臂肩部提前着色。非标准模型、爬行/游泳姿势的逐世界像素水线以及其他着色模组组合未专门验证。[代码审查](review.md)记录了这些范围。

官方 3D Skin Layers 1.11.3 及内嵌库仍有原有的资源包 `supported_formats` 描述错误，原始错误保留在合载日志。只有该已知精确格式错误允许继续，其余加载与图形错误仍中止检查；实际游戏、可见皮肤网格和 MFQM 胶膜同绘已完成。未修改或打包第三方 JAR。
