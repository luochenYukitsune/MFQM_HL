# 实施计划

1. 在 `client/WetAdhesiveStyle` 实现浅深高度、薄壳厚度、封闭六边管、拉伸变细、胶水加粗和断裂回缩；测试先失败再实现，接入 Gradle `check`。
2. 扩展 `AdhesiveFeetSampler.Foot`，使用原生脚部矩阵和公开立方体边界提取方向、尺寸，用弱键缓存；FirstPersonCompatibility 平移时保留完整数据。
3. AdhesiveTetherRenderer 每接触仅提交一根从介质根部到脚部薄壳的连续管，去除分叉和共同根部节点。胶水及涂胶板半径加倍，根部受实际介质边界限制。每脚薄壳仅绘制一次。
4. 实际合载断言一接触一根、封闭截面、加粗、双脚两层膜、端点贴面、根部在介质内。检查必要截图，保留连接数量异常诊断，不降低 64 接触断言。
5. 主代理需求与代码审查；构建、工具和 JAR 校验通过后更新 README、玩法说明、最终报告，并保存 Git。沿用之前同一物理实现的回归证据，注明候选版本哈希。隔离游戏仅在工作目录运行。
