# 运动和汉化复核

本轮沿用已有的实现与审查代理，没有新增代理。主代理复核代理写入的生产代码、测试边界及最终汉化接入；以下记录的是实际检查范围。

- 目标源码为 Minecraft 1.21.11 / NeoForge 21.11.45。流体 travel 的固定加速度绕过旧属性减速，不能只调整 `MOVEMENT_SPEED`；约束移到实际 move 前，并保留原版水路径。
- `ServerPlayer` 的世界 tick 与连接 `doTick` 顺序不同于普通生物。后者会恢复网络基准位置；取消其重复原生 travel，保留一次服务端兜底，避免附加阻尼及二次力。
- 同步附件替换不应重播已消费的下陷，也不应重启救援窗口。客户端用按实体弱引用保存的累积账本与序号；维度切换、介质退出及时钟回退清理暂态运动历史。
- 不能把所有向上速度都当作救援，否则受击会持续飞升。只有救援及真实击退/爆炸事件提供有限窗口，窗口结束后恢复正常规则；真实受击测试使用原版伤害链发包。
- 原版 aiStep 会清除微小惯性，Entity.move 会忽略被地板截断的微小步长。连续同介质的自有低速惯性可以恢复；不足阈值的水平位移累积后仍交给原版碰撞移动。换介质/断续 tick 清零，救援或外力使用新速度，撞墙时实际移动仍受原版裁剪，不添加人为最低速度。
- 跳跃限制同时覆盖流体和地面跳跃；保留原始输入供挣扎使用。水、飞行、旁观、介质免疫及乘客按各自规则处理。创造模式地面默认受困且免伤，关闭配置时恢复豁免。
- 汉化审查发现并修正沙子桶/丛林流沙桶、抓钩附着限制、救生衣提示、视野遮挡配置、抓钩辅助实体附着、伤害倍率等语义问题。未把旧版未实现的“手持蜂蜡融化”“水中救生衣浮力”提示接入现有物品。
- 配置界面仅在客户端分发入口注册，通用构造器无新增客户端依赖。宝箱名改为可翻译组件；所有英文语言键均有中文对应，死亡消息格式参数可合法重排且身份一致。
- 默认主回归不含飞行项目。飞行对照是独立显式选项，主套件每个测量 tick 检查双方 `flying=false`；没有逐 tick 重设位置/速度，也不生成截图。

完整第三方模组合载和两个真人客户端的网络操作仍不在本轮验证范围。深池达到极限束缚时三种黏性流体会落在同一最低移动系数；浅池及流动薄层的移动速度保持胶水 < 焦油 < 蜂蜜。
