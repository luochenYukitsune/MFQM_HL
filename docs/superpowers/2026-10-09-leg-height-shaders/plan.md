# 实施计划

1. 扩展纯几何测试：少量高位连接比例、稳定随机、腿长缩放、旋转姿势、胶膜深度和根部边界。
2. 给 `WetAdhesiveStyle.Frame` 带入本体采样得到的小腿高度。`AdhesiveFeetSampler`、第一人称平移和 `AdhesiveTetherRenderer` 保留此几何信息，高位端沿腿轴生成。
3. 在 `CoatingAppearance` 集中材质外观系数，供立体与平面身体覆盖共用；胶水小幅增强，其他黏性介质降低遮盖强度。池面和黏丝按用户确认范围处理。
4. 只读审查项目全部渲染与光影包，修复已确认缺陷。立体覆盖采用纹理 alpha；平面和远景使用六面模型与稳定名称的缓存贴图。新增独立光影测试入口，确认 Iris 真正在使用选定的包，不能把自动回退原版当成通过。
5. 编译和运行相关纯测试，简化场景验证高位连接、透明池面、身上覆盖和第一人称。保存少量必要截图及各包状态；记录外部光影自身限制。
6. 审查改动并更新中文文档、开发版号，输出 JAR。正常启动不启用测试入口。
7. 根据用户池面反馈增加正对四种池面的固定截图。先保存失败外观，再实现 ITT／ITPR 的限定材质桥：碰撞安全 ID、编译时 getter、ITPR 深度与块光；纯测试验证普通水/玻璃不被覆盖，随后对照同场景实际截图。
