# 小腿连接点、材质透明度与光影兼容

用户已确认约四分之一的黏丝稳定随机抬高到小腿中部；胶水覆盖稍微提高白色半透明强度，保留皮肤细节。高位点沿实际腿部模型的方向和缩放计算，走路、挣扎及 FirstPersonModel 下仍贴合腿面。其余连接保留脚踝高度。胶膜本身的覆盖范围继续由接触深度决定，不能因此污染上半身。

介质端继续完全位于实际液体的方块内部，保持现有近底部根部、短粗立体胶带、密度上限、物理活动范围和束缚规则。

用户已确认蜂蜜、焦油和黏液的身上覆盖、黏丝和池面都更半透明，保留原色。代码采用共同的材质外观系数，同时保留游戏内全局与单材质设置，避免只修改配置默认值而导致旧配置不生效。胶水身体覆盖增加 20%；蜂蜜和黏液覆盖为原强度的 78%，焦油为 85%。对应源/流动动画只降低 alpha，RGB 和帧尺寸不变。

光影审查覆盖所有自定义实体、方块实体、流体、粒子、模型、玩家覆盖及第一人称桥接。优先原版已被 Iris 映射的渲染管线，不引入自定义 OpenGL 状态或包专用硬编码材料号。只读检查用户的九个光影包，在工作区独立实例验证，真实支持范围以加载状态、日志和截图为依据。

用户追加优先适配 ITT 与 ITPR，对应本地 IterationT 3.2.0 和 IterationRP Alpha 0.8.26 hotfix。两个包忽略顶点 alpha，实体与流体只使用纹理透明度。因此立体身体覆盖和黏丝使用带边距的透明度纹理格，不透明顶点 RGB 保留原色，最终 alpha 只计算一次。平面 LOD 保留六面模型，最终透明度烘入缓存贴图；缓存纹理名由源贴图与强度固定生成，避免 RenderTypes 永久缓存增长。Iris 的阴影 pass 不使用第一人称临时偏移的足位缓存。

不修改桌面源码快照，不生成新美术图像，不自动发布 GitHub。测试截图用于验证实际渲染。

用户实测指出 ITT／ITPR 的部分池面变得完全通透，已确认目标是胶水、蜂蜜等池面。只验证加载和根部几何不足以验收池面。两包默认把未知透明流体分类为玻璃，白胶的白色不能通过玻璃吸收呈现。限定识别本地两版水绘制源码：为六种 MFQM 黏性流体选择不占用现有映射的临时材质 ID，编译时将 ITT 接入普通 alpha 混合，ITPR 接入它现有的透明颜色合成，并补其必要的深度记录与块光。避免玻璃吸收造成重复染色；其他物体、原版水和玻璃保持原路径。Iris 的源码 getter 在 ID 映射加载之后才应用修改，兼容其实际加载顺序。原光影 ZIP 和配置不会被改写；未知源码或已有专属 MFQM 映射时保持原样。

上述池面路径属于兼容降级：不再使用两包的玻璃折射及玻璃反射，优先实现有颜色、有纹理、能透出池底的半透明。不能把这一实现宣传为所有光影高级材质功能的完整支持。
