# 0.7.5-inside 贴肤渲染与整合发布

目标为 Minecraft 1.21.11、NeoForge 21.11.45、Java 21。按用户要求先备份，再修正皮肤内部随机附着和身体胶层的塑料壳感，整合此前尚未单独发布的全项目审查修复；发布状态继续为 Pre-release，开发构建改用 `-inside` 后缀。

## 备份与实现

修改前源码保存在工作目录 `exports/backups/before-0.7.5-inside/source.zip`，基线提交 `fa740275df3a32dd0285aa3736905f50e354fc69`，SHA-256 为 `ec4f6da44be8c2ee2e6a1ae87c13c6bcbd096718a9913fc61ab595f2bef83d33`。此前全量 Git 历史和 0.7.3 原 JAR 备份继续保留，见 [全项目审查报告](../2026-10-10-full-audit/final_report.md)。

身体端的随机量只选择表面方向和高度，随后投射到当前原生腿部／可见衣物网格。端点位于表面外侧；粗截面在靠近身体时裁整到该表面外，保留根部、稳定随机、连续无分叉胶带和断裂回缩。

全部身体残留改为两层实际表面膜：基础皮肤间距固定为 0.012 模型像素，默认微起伏最大 0.018 模型像素；衣物仅沿其实际可见面覆膜。可选 3D Skin Layers 直接捕获当前 mesh 和其 OffsetProvider 变换，不按最大尺寸撑出整块盒子；透明洞和隐藏 mesh 保持空缺。第一人称袖子使用该模组专用偏移，FirstPersonModel 身体沿用同帧原生姿态。

原版衣物的可见像素几何缓存有界；远景／关闭细节采用六个真实面，覆盖 alpha 和皮肤镂空烘焙到纹理。远近两条路径使用同一可见门限和胶层强度。API 与单个 mesh 失败分别处理，只省略无法确认的外层，重载清理临时失败状态；延期提交持有不可变几何和当前姿态快照。

中文说明同步为贴肤薄膜／胶层微起伏，保留旧配置键、原有浸入深度和水洗。服务器活动范围、挣扎与拉力、默认约 512 根和最高 8192 根预算、黏丝完整根部浸没规则保持原有设计。所有 339 张运行 PNG 与 0.7.3 基线一致。

## 验证

- 两条新几何回归先在旧实现上失败：粗截面侵入腿面、默认像素凸起过厚；修正后通过。`check build prepareInstalledClient` 的 13 个 Java 程序共 65636 项断言／样本／运动组检查通过，新增实际表面投射检查 5122 项。
- 最终打包 JAR 与 FirstPersonModel 2.7.3、3D Skin Layers 1.11.3 合载通过。600 个解剖覆盖组合、宽／窄皮肤、身体与真实手臂、隐藏／失败网格和重载恢复、实际 voxel 自定义尺寸、全部材质及中文强度开关通过。
- 第一人称站立、潜行、转身、开关切换及真实胶水 64 个接触的最大脚部误差约 1.335×10⁻⁷ 格。本次实际场景显示 55 束／440 根；端点距原生表面小于 0.024 模型像素，整个近身粗截面在皮肤外侧，完整根帽仍在原介质内部。玩家没有飞行；实际有限短跳也通过。
- 未安装可选模组的真实客户端单独验证基础皮肤／透明衣物路径，包括缓存复用、六面 LOD、逐像素透明镂空与胶层强度一致、600 个蒙版、手臂及资源重载。
- 整合修复的开发专用服务器 84 项检查和实际 `/reload` 通过，涵盖装备守恒、伤害、移除、传送、剪刀权限／耐久和未知邻区块。本项服务器使用开发类，客户端使用实际安装 JAR，分别记录。
- 最终 JAR 元数据与资源引用为 0 错误；50 张解剖覆盖、128 种拼接板状态通过。此前完整 23 场景行走／跳跃与保存重启回归见审查报告，本轮没有重复整套玩法矩阵。

只复用一名只读审查代理；LOD、失败降级和远近 alpha 三个确认问题均修复并复核，详见 [review.md](review.md)。两次实机夹具误报的原因及处理也在该记录中保留，未将 tick 数当作帧数，也未将异步实体计数冒充物理连接数。

仅在候选版本保存三张必要截图并实际查看：宽／窄皮肤胶层对比、第一人称贴肤与黏丝、第三人称近景黏丝。最终回归不新增截图。候选 JAR SHA-256 为 `a6267160dff008862481a5b5cc160c5cf117fa71507ecd5c42b7baeacf59dcda`；截图之后仅修兼容失败降级、LOD 和夹具时序，不将候选截图表述为最终 JAR 截图。日志及两版产物信息见 [validation.json](validation.json)。
