# 独立审查与修复记录

本次按已批准的设计及实施计划施工。规则、注册／配方、粘鼠板、留靴／绳索、动物足部、客户端动作、世界生成分别经 subagent 实现或审查；主代理负责接入、真实运行与交付。最终再次审查实际接入后的源码，不能以模块自行通过代替集成验收。

## 主要问题与处理

- 装备转移回调重入可能复制靴子：以插入锁禁止尚未完成转移的装备被回收，插入成功后再清空装备槽。真实插入回调回归先失败，修复后通过。
- 胶水静止仍受客户端重力预测影响：服务端清速度无法撤销已上报的位置。双侧接触期间临时取消重力，离开／免疫／死亡／换维度清理；实际 JAR 的浅、深胶水静止高度回归验证。
- 换维度后同坐标旧锚点、拖拽和输入残留：换维度事件立即清理旧世界辅助实体及临时状态，tick 开头另有维度身份检查，且位于重复 tick 去重之前。
- 生物端点只按包围盒估算不足以贴合动作：使用原版实际烘焙模型取脚部变换，覆盖七种指定动物的成年／幼年、坐姿／跳跃和变种；采样使用独立模型，避免修改已提交的渲染状态。
- 第一人称手持物与挣扎动作冲突：复用原版手臂／物品渲染入口，保留实际使用工具姿势，双手地图避免重复绘制副手。
- 完全平地与树冠高度要求导致自然胶水池无法落地：真实新区块样本保留零发现证据，新增一格天然岸回归先失败；改为有界地面查找及最多两格天然缓坡适配，概率不变。树干、箱子、液体、床岩和建筑块仍在完整预检中拒绝。
- 测试实例 TOML 的 UTF-8 BOM 导致 NightConfig 启动失败：启动前使用无 BOM UTF-8 写回并以 TOML 解析器检查。启动器独占实例锁，遇到游戏错误结束自己启动的 Java 进程。
- 胶水中的原版持续跳跃仍能在物理 Post 处理前移动角色：实际 JAR 先复现 60 tick 上浮 1.209 格；仅在受困接触下抑制原版跳跃冲量，保留原始输入、挣扎累计和外部救援速度。再次实际 JAR 测试保持原高度，创造模式仍正常跳跃。另一位代理独立核查了实际 1.21.11 调用点与生物回归。
- 全新粘鼠板可以被原版跳跃绕过：实际 JAR 先复现客户端最高上浮 1.486 格。扩展双方接触条件，只对未释放的板限制冲量；释放快照按位置和涂层同步，并更新协议 3。
- 已释放后落回同一板会误重置进度：独立复审指出无锚点且短时离板会触发旧重置分支，实际猪运行先失败。修复后保留同一涂层的释放状态；实际首次／再次跳跃、落回、补胶、换板与耗尽测试均通过。

粘鼠板跳跃边界与最后的实际 JAR 验收结果见 [最终报告](final_report.md)。真实失败证据、修复后的执行结果分别记录，不把缺少自然生成观察的样本当作成功。
