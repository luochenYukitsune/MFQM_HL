# 胶水、粘鼠板与黏连开发验收

目标版本：Minecraft 1.21.11、NeoForge 21.11.45、Java 21；开发版本为 0.6.1-dev。按用户批准的设计施工，全部操作限当前工作目录。桌面副本和已发布的 GitHub 0.6.0 保持原状。

## 实现范围

- 白色半透明胶水的源／流动流体、胶水桶、容器正确的合成配方。浅胶水黏脚，深胶水允许吞没及窒息；静止保持深度，反复挣扎后开始下陷。
- 1/16 格薄的粘鼠板：三个空底板合成、放置支撑、胶水桶补胶、涂层消耗、回收保留涂层。玩家及指定中小型生物受困，创造／旁观／飞行玩家免疫。
- 分介质距离的腿脚黏膜与多条拉丝；物理连接有数量上限与合力上限，超距立即去除物理束缚并短暂视觉回缩。水只清残留。
- 默认 F 的逐次挣扎、冷却、饥饿消耗与效率变化；浅层拔脚、深层扭身撑拉、第一人称双手和可关闭的轻微镜头起伏。绳索手持右键收放，F 不用于放绳。
- 胶水／涂胶板上的小概率留靴，保存完整耐久、附魔、名称；空手、长棍和绳索辅助回收，满背包、插入失败／重入、区块卸载与重启不复制或吞掉装备。
- 主世界森林／沼泽新胶水池，原有遗迹少量地面粘鼠板及宝箱材料。关闭配置、区块边界、密封池壁／池底和保护地形均纳入检查。
- AI 胶水与木板源材质及 16 张可用运行贴图：64 个液体动画帧、10 级玩家 UV 蒙层、桶图标、板面和黏丝。另有设计参考图，明确与游戏实拍区分。

玩法、配方及操作详见 [中文使用说明](../../adhesive-gameplay.md)。现有注册完整性保持：51 个方块、14 对流体、180 个物品、165 项创造栏、18 种实体、207 条核心配方。

## 已执行的验证

`gradlew.bat build`：26 组运动与 35 个边界样本、241 项黏连规则、739 项挣扎断言、378 项动作姿态断言全部通过。饱食正常的新板合理连续挣扎耗时 19.8 秒；饥饿时约 33.6 秒。

资源／JAR 检查为零错误，Java 与目标 Minecraft／NeoForge 版本通过。材质检查验证 16 张新增贴图、动画接缝／透明度／UV，319 个此前资源哈希未变；之前已满意的 100 张更新材质也通过校验。隔离游戏启动器的 12 项 Python 检查通过。

最终服务端实际运行通过 **66 组**，覆盖配方／容器、束缚、救援、留靴、真实生物、换维度、结构奖励、地形保护和真实 `/reload`。12:04:48 的准备进程保存装备，12:13:58 的独立恢复进程核验完整组件并唯一回收；最终服务器日志见 [tdd-board-jump-server-green.log](tdd-board-jump-server-green.log)。

实际客户端从独立游戏的 `mods` 目录加载构建 JAR；代码来源断言排除开发类注入。60 个实际烘焙模型场景覆盖玩家宽／细臂、七种动物的成年／幼年／变种／坐姿／跳跃。F 短按真正通过网络每次只接受一次，OS 重复不增加挣扎，手持组件保留。

## 问题修复与审查

独立 subagent 复核后，修复了装备插入重入复制、客户端胶水重力预测、同坐标换维度状态残留、动物脚部端点及第一人称手部问题。真实持续空格先复现胶水 60 tick 上浮 1.209 格，修复后生存玩家保持原高度，创造模式正常跳跃；生物真实 `tick` 保留挣扎意图、向上救援及普通干地跳跃。

粘鼠板也先真实复现跳跃绕过，再修复双方的未释放板跳跃冲量。第二次独立复审指出落回同板会错误重置释放状态，实际服务器先复现失败再修复。最终真实生物回归覆盖首次释放、完整落回、再次起跳、再次落回、原位补胶、新板与涂层耗尽。释放快照按位置／涂层核验并同步给客户端；网络协议更新为 3，客户端与服务端必须安装同一开发版。

用户截图中的启动错误来自测试实例 `fml.toml` 的 UTF-8 BOM。已修正为无 BOM UTF-8，启动前解析配置；实例锁避免并发使用同一游戏，异常只结束启动器自己的 Java 进程。之后的实际 JAR 游戏已能正常启动并保存有效截图。

最后的客户端板弱化场景还发现测试夹具共用板：牛与玩家的脚部范围都命中 `(60,253,0)`，牛的慢速自救也会磨耗这块板。实际日志记录玩家 effort 23.25 时 charge 已为 2，effort 30.25 时板合法耗尽，随后角色自由且进度清零；继续要求个人 effort 达到 34 的夹具因此超时。修正仅在截图完成后把牛移到独立板，不改生产消耗规则或 34 的个人弱化门槛。

完整审查见 [review.md](review.md)，胶水跳跃 RED/GREEN 见 [tdd-glue-jump.md](tdd-glue-jump.md)，并有第二位代理的[独立增量审查](review-glue-jump-independent.md)与[玩法终审结论](final-behavior-review.md)。

## 验收边界

这些结果覆盖实际 NeoForge 游戏中的自动输入、真实实体物理与截图检查，不等于两个真人的联机手感验收。所有第三方模组合载、所有世界种子的池频率及长时间生存平衡仍需额外试玩。当前保持开发版，未发布 GitHub。
