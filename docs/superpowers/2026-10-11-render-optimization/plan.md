# 实施与验证计划

1. 逐文件阅读全部 Java、测试、Gradle 和工具代码，记录覆盖清单；资源用完整解析和打包校验检查。
2. 试验预计算皮肤查询，并通过随机、边界、退化与不可变快照的等价检查；微基准发现收益随密度变化，最终撤回此实现与相关新增 API。
3. 用独立的旧两遍裁剪实现验证 1,024 根随机黏丝，随后将裁剪移动到共享环顶点；保持最终网格完全相同。单连接位置及四顶点提交去除重复计算和数组。
4. 辅助审查实现单连接有效性判断，运行与旧 singleton 聚合的等价测试，保持最终聚合不变。
5. 新图标缩放到 256×256 RGB PNG，保留生成原图和旧横幅，修正 metadata，删除描述中已雪藏的按键宣传。JAR 验证器检查方形尺寸和完整 PNG 解码。
6. 运行完整构建、纯 Java 测试、JAR 校验。旧／新黏丝几何生成用同输入、同 JVM 做交替顺序微基准，记录中位耗时和线程分配量；不能等同于整机 FPS。未采用的预计算查询也保留测量结果。
7. 用隔离实例运行简化的贴肤／资源重载／第一人称兼容回归；必要时生成一张检查截图，避免无关图像。复核改动并产出本地 JAR、图标、审查报告；本次未请求 GitHub 发布。
