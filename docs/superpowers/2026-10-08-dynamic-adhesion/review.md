# 0.6.6-dev 规格与代码审查

依据用户批准的 [设计](design.md) 和 [计划](plan.md)，由主代理审查。按用户节省开支的要求，本次未启动额外子代理。比较基线为 `1109513`，范围包含玩法、同步、客户端渲染、配置、汉化及测试工具。

## 规格检查

- 活动连接最多 64 条；同格移动至少 0.08 格且间隔至少 3 tick 才新增接触，静止不补丝。先移除最旧物理连接再新增，旧显示实体仅保留 6 tick 回缩；更新不会重置活动原点和挣扎进度。真实客户端 W/S 及专用服务器均验证到 64 条。
- 水平与竖向断裂独立，竖向默认胶水 4 格、蜂蜜/黏液 2.7 格、焦油/胶板 2 格。数量大于两条时按 `2 / activeCount` 归一化，总力不超过 0.045；保留相反方向抵消和非有限值防护。
- 根部按真实流体高度、实体介质和 1/16 格胶板分别约束。中心、根部横截面均留在占据体积内，液面下降更新原连接而不换身份；移除介质即失效。服务端和客户端复用 `AdhesiveSurface`，薄流层与边缘有专项检查。
- 白名单只保留胶水、焦油、蜂蜜、下陷黏液/黏液和涂胶板。泥沙等没有连接，仍进入原有物理和覆盖路径；真实泥潭行走结果连接数为 0。
- 身体覆盖使用当次原生玩家模型部件，继承显隐、位移和姿势；FirstPersonModel 的逐渲染状态 `isCameraEntity()` 避免延迟提交时依赖短暂全局标记。第一人称头部覆盖明确跳过，手臂/身体跟随上游模型。可选反射仅存在于客户端，缺失 API 时只警告一次并保留原生部件显隐。
- 五类残留全部使用现有高度蒙版的像素几何；材质 RGB、源透明度、历史渐隐和浸入高度保留。全局与材质透明度/厚度相乘，显示数量取上限较小值；透明度 0 隐藏，厚度 0 回退平面，不改变物理。原 `glueCoating3d` 键继续可读，现为全材质开关。

## 生命周期、同步与开销

- 新增黏膜标记走同步实体数据；协议从 5 升为 6，要求两端一起更新。真实安装检查确认从 `mods` 中的 JAR 加载；专用服务器启动、75 组玩法检查与 `/reload` 通过，没有引用客户端类的加载错误。
- 每只脚仅最新连接绘制黏膜，避免 64 层叠加；每帧按角色缓存双脚采样，每 tick 缓存显示筛选。缓存分别限制为 128、256 个目标，使用弱引用或 ID，避免静态缓存持有退出世界。
- 覆盖几何 LRU 最多 96 项，厚度按 1/16 量化，资源重载清理；延迟几何回调捕获不可变局部值。16 格外的覆盖回退平面、黏丝降为 3 段。
- 显示上限调到 16 后服务器与客户端仍有 64 条物理连接，证明显示不干预玩法。未声称已完成大量生物同时受困的帧率或网络压力基准。
- 第三方 JAR 仅在忽略的隔离测试目录使用并验证哈希，不被打入 MFQM。没有新增 AI 图像、改动桌面副本或日常游戏实例。

## 审查中处理的事项

- 用原生部件替换非胶水残留的独立模型，修复第一人称位移/显隐与其他材质立体覆盖路径不一致。
- 将薄层根部宽度限制在垂直净空内；服务端新增 64 个既有根部随液面降低且身份不变的回归。
- 将缓存世界/实体改为弱引用，保持缓存容量限制。
- 动态客户端夹具遇到旧隔离配置 `creativeGroundPhysics=false` 时会错误测试免疫角色；现显式开启地面物理并在退出时恢复，真实非飞行 W/S 验收通过。
- Python 临时目录测试在沙箱出现权限错误；在允许的执行环境重测 29 项全部通过，未删改断言规避失败。

本次审查未发现尚待处理的严重或主要缺陷。两个真人联网、非标准玩家模型及其他着色模组组合未覆盖。官方可选外观模组的资源包描述格式错误保留在日志并在 [验收报告](final_report.md) 说明。
