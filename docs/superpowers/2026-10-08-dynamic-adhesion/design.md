# 第一人称覆盖兼容、动态黏丝与全材质立体残留

## 已确认的体验

支持 Minecraft 1.21.11 / NeoForge 21.11.45。只修改当前工作目录，不更新桌面副本或发布 Release。默认每个受困角色最多 64 条主黏丝，优先密集效果；运动接触新增、最旧连接依次断开。保留胶水、焦油、蜂蜜、黏液和涂胶粘鼠板的黏丝；泥潭、沼泽、黏土及沙类移除黏丝，原有下陷、阻力、挣扎和身上残留继续生效。

竖向断裂距离独立设置：胶水 4 格、蜂蜜与黏液 2.7 格、焦油与粘鼠板 2 格。水平活动半径仍按现有设定，不因竖向延长而扩大。连续跳跃不得因此成为飞行；F 挣扎、救援和留靴机制保留。

## 接触与连接

每只脚实际触及介质时采样接触位置。同一方块内移动也能增加新连接，但静止不会无限生成；设最小移动间距和生成间隔，避免每帧抖动产生实体。达到 64 条后先让最旧连接失效并短暂回缩，再加入新连接。静止的旧连接不会追着角色移动。

黏丝根部放在实际介质体积内，贴近其表面；薄层、流动液面、方块边缘和粘鼠板分别检查。根部的横向宽度同样收进介质，避免中心虽在内、粗丝却越界。液面变化时更新根部高度；介质消失或变成非黏性物质后立即移除相应连接。根部与脚踝、腿部姿态分别处理。

多丝共用受困状态与水平原点，不因补丝重置挣扎进度或活动范围。总拉力有硬上限，并按有效连接数归一化，增加显示数量不会额外增加束缚。断裂回缩有数量和寿命限制。

## FirstPersonModel 与覆盖材质

参考 FirstPersonModel 官方 2.7.3 源码及 1.21.11 NeoForge 发行包。所有材质的身体覆盖统一跟随当前原生玩家模型部件，继承第一人称模型的位移、隐藏部件和动作；第一人称全身渲染隐藏头部覆盖。读取其可选 API 和渲染状态标记，不把该模组设为必装依赖，未安装或关闭时继续使用原版路径。

胶水、焦油、蜂蜜、黏液、泥沙及其他残留全部使用现有高度蒙版生成逐像素凸起，保留各自颜色和透明度；立体覆盖与原版手臂、宽/细手臂皮肤、3D Skin Layers 间距兼容。保持此前修正的浸入高度、水洗和历史残留规则，不提前污染上半身，不重新生成无关图像。

## 游戏内显示设置

中文客户端配置提供全局覆盖透明度、凸起厚度、黏丝显示数量，并允许按胶水、焦油、蜂蜜、黏液、泥沙等材质单独调整。默认乘数保持当前胶水的较淡效果，其他材质保留自身色调。设置只影响显示；调低或关闭不会改变服务器黏力。保留立体覆盖总开关，远距离降低几何细节，限制网格缓存。

## 验证

先加入可失败的行为检查：非黏性白名单、竖向与水平独立断裂、64 条 FIFO 替换及总力、根部包含关系和液面变化、透明度与厚度、材质色调。执行构建与现有回归，审查联机同步和服务器客户端隔离。

把构建出的 JAR 放入工作区隔离游戏实例，分别测试原版、FirstPersonModel、与 3D Skin Layers 合装；检查第一人称下视/潜行/持物、第三人称、浅层与深层、移动补丝与断裂、边缘和流体根部。记录真实日志，并只截取核实这些效果所需的截图。性能以密集场景实际观测说明，不预先承诺帧率。
