# 实施计划

1. 在真实第一人称身体与黏丝提交处增加仅验收启用的同帧矩阵对齐证据，实际涂胶板站立测试先复现偏移失败。
2. 从相机角色原生渲染状态采样双脚端点，每帧清除、仅同角色同帧使用，避免独立采样忽略上游的位置修正。
3. 为短丝淡出和细束分散规则加入纯 Java 边界测试，先失败再实现；渲染端限制根部体积，每接触五条细丝，保持服务端物理不变。
4. 扩展实际客户端验收至潜行、转身和视角切换，合载用户的动画模组，检查两张必要截图及日志。构建与现有范围/跳跃/FOV/挣扎回归通过后审查、记录并提交 Git。
5. 根据追加的身体覆盖反馈，先验证旧凸起超过 0.12 模型像素的失败，再减半凸起、去除不可见外层的空隙；补充实际皮肤外层检查和一张宽/细臂覆盖对照截图。

由主代理实施和审查，不新增子代理。修复版本 0.6.7-dev。
