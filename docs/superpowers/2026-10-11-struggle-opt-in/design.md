# 专用挣扎按键改为手动启用

用户已确认：专用 F 挣扎默认关闭，可在模组设置菜单手动开启，不显示操作提示。随后要求用此修改替换原 0.7.5-inside，更新 GitHub 的同一预发布及 README。

新增客户端布尔设置，默认 false，修改后立即生效。关闭时不捕获、发送或保留专用挣扎输入，不吞掉原版换手点击；按键设置列表也隐藏该项并排除其冲突提示，但保留原有自定义键位存储。开启后继续使用原有频率限制、动作和服务器校验。正常走路、跳跃、黏力与下陷继续使用原来的输入同步。

彻底移除自动受困按键提示与工具上的 F 介绍。README 不再宣传或说明专用挣扎。设置内仍提供中文开关说明，让用户可自主开启。保留历史审查记录，不改写以前的测试事实。

构建并进行一次定向隔离客户端验证，包括默认关闭、换手、菜单隐藏、开启后的短按与频率限制，以及关闭后队列不重放。保留旧发布文件备份，再更新仓库、v0.7.5 标签、同名 JAR、源码 ZIP 和校验清单，发布状态仍为 Pre-release。

接口依据：[NeoForge 1.21.11 按键文档](https://docs.neoforged.net/docs/1.21.11/misc/keymappings/)及本项目使用的 21.11.45 源码。按键菜单过滤只改变菜单读取的列表，不修改 Options.keyMappings，避免自定义键位丢失。
