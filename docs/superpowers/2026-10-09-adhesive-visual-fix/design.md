# 黏丝与粘鼠板显示修正

用户确认黏丝改为边缘平顺、宽度变化均匀的立体胶带，并进一步纠正：需要变直的是介质端，不是提高身体端。根部向所在介质格的底部延伸，保留完整根部在介质内的约束；浅涂层仍按实际厚度限制。身体连接位置、64 个物理连接、每连接 8 根独立显示和活动范围保持现有规则。

增强胶带宽度及可见度，减小中段收腰和下垂，保留闭合的立体截面与断裂回缩。内部延长不应缩短介质表面以上的显示距离。

实际游戏仍加载 0.6.9-dev，包内没有拼接模型。除交付新包外，修复旧存档加载后连接属性默认关闭的问题：在区块完成加载后的服务器 tick 更新包含粘鼠板的区块，并刷新已加载的相邻板。胶量与掉落独立。

真实截图进一步确认贴图本身有两像素透明框：旧接缝模型虽扩展到格边，仍采样透明区域而露出木色。将胶面 UV 限制在内部有效像素，连接边使用对应边缘像素延伸；保留原 PNG 与单板物品图。

简化测试：纯几何回归、资源检查、一次隔离安装 JAR 的游戏测试；实际放置 2×2 板、移除恢复边框、模拟旧连接属性后刷新，检查真实烘焙面。只保存拼接板和黏丝两张必要截图。不运行完整玩法、兼容模组矩阵，不生成图像。
