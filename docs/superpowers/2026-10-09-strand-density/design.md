# 黏丝密度、随机外观与表面气泡修正

用户已批准：每个角色默认最多约 512 根，显示可调上限扩展到 8192 根；刚接触时也需要较浓密，走动后逐渐增加。客户端每个接触的基础密度默认 8、范围 1～128，仍最多 64 个物理接触。少量接触的绘制密度最多提高四倍，接触积累后回到基础密度；总显示仍不超过基础密度乘 64，不添加物理实体或网络消息。高密度几何用三段平顺截面，减少绘制成本。

用户选择减少整齐扇形感，并要求多增加黏的位置、大小等随机变量。每根的随机量由接触实体与黏丝序号独立混合生成，根部散布、腿面横向位置、附着高度、宽度、截面厚度、轻微弯曲使用不同随机通道。随机量保持稳定，角色姿势与液面变化时只更新必要坐标。约四分之一仍最高到小腿中部；横向位置只在朝向根部的腿面内偏移，避免穿腿。胶带宽度平顺，无分叉、无锯齿轮廓；完整根部截面继续限制在介质内部。

用户确认巨型粒子是介质表面的方形泡泡。现有泡泡将整张方块 PNG 绘成半格宽的方形，动画 PNG 也可能整张采样。改为最大约 0.11 格直径的小型八面气泡凸起，通过方块图集采样当前帧，保留介质颜色、声音、少量破裂粒子与显示开关。不会改动遮眼效果。

验证采用相关纯几何测试、两款优先光影的固定小场景、一次无 Iris 的启动检查。保留必要截图，记录真实包加载、根部边界、附着位置及气泡尺寸，不生成美术图像。用户后续明确授权拆成 0.7.2-dev 与 0.7.3-dev，分别保存新的桌面源码副本并通过 GitHub CLI 发布 Pre-release；旧桌面快照保持原样。
