# 0.7.3-dev 实施与验证

Minecraft 1.21.11 / NeoForge 21.11.45 / Java 21。此更新只增加可调黏丝上限、自适应初始密度、稳定随机外观和小型表面气泡；包含已独立发布的 0.7.2-dev 兼容改进。

最终 JAR：`MFQM-neoforge-1.21.11-0.7.3-dev.jar`。

SHA-256：`f0a415215c35b7193b1a34674607cad62b1bfc98468ff4a2167aa0239e523815`。

## 已完成验证

- `build prepareInstalledClient -PmfqmClientChecks --offline` 通过。短丝预算／种子测试 9742 项、湿黏几何测试 7031 项、气泡尺寸／绕序测试 41665 项；完整 `check` 同时覆盖现有活动范围、黏力、挣扎、身体覆盖和光影契约。
- `verify_jar.py` 检查实际 0.7.3-dev 元数据、Java 21 与资源通过；`verify_port.py` 对实际 JAR 检查 0 错误。中文配置说明同步更新，密度可调至 128；默认 8。
- 最终 JAR 在 ITT 3.2.0 与 ITPR Alpha 0.8.26 hotfix 的隔离实例中通过实际 Iris／Sodium／FirstPersonModel／3D Skin Layers 渲染。ITT 记录 380 根可见黏丝、98 个高位点；ITPR 400 根、88 个高位点。角色关闭飞行，实际 W/S 移动；全部根部截面在介质内，身体端不超过采样小腿中部。
- 实际渲染器接受 128 的密度配置，使用三段几何；默认场景仍受 512 根预算约束。宽度与腿面位置各有多于 16 种不同值。128 种种子跨腿角连续性已先复现失败再修正。
- 六种材质的小气泡使用真实方块图集 UV，尺寸不超过约 0.112 格，并在测试世界中确认实际绘制提交。测试人为并排展示胶水、蜂蜜、焦油、黏液、泥巴和流沙气泡，所以截图中的气泡颜色会混合；正常游戏仍按所在介质显示。
- 两包第一人称原生腿脚与黏丝矩阵误差均约 `3.33e-8` 格；立体与平面覆盖均真实提交。池面临时材质映射与源/流动状态映射均正确生效。
- 池面截图前检查客户端实际在 `(211.5,261,10.5)`、`onGround=true`。已查看两包固定四池图片，白胶保持乳白半透明，蜂蜜、焦油与黏液保留颜色，底部棋盘仍可透出。必要截图和精简日志保存在 `evidence/`。
- 最终 JAR 在未安装 Iris 的客户端完成 600 种身体掩码、宽／细模型、手臂、全材质显示设置与资源重载检查，截图关闭。一次运行在全部断言通过后退出时出现 Netty `ClosedChannelException`；保留失败日志，只重跑该范围，最终干净退出通过，未放宽错误过滤。

## 交付与边界

只使用一个已有的只读审查代理；其发现的腿角跳变已修正。初次启动参数与一次池面截图转场问题已改进测试并复核，错误视角未作为最终证据保留。

8192 是可配置上限，实际数量受接触组数、材质上限及短距离淡出约束；未进行 8192 根长期压力或多人负载测试。推荐从默认 512 根预算开始调整。服务器连接数量、拉力与活动半径不变。光影的折射、反射、PBR 等限制沿用 0.7.2-dev，详见光影兼容说明。

按用户授权独立发布 v0.7.2 与 v0.7.3，均为中文 Pre-release；JAR 文件名与内部版本保留 `-dev`。各版本保存独立源码 ZIP、校验值和新的桌面副本；旧桌面快照、用户光影 ZIP、光影配置和存档保持原样。
