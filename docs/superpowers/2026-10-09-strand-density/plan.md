# 0.7.3-dev 实施计划

用户已批准设计；0.7.2-dev 已独立提交、打包并发布，不将后续改动混入该版本。

1. 为 `CompactStrandStyle`、`WetAdhesiveStyle` 增加预算、种子独立性、稳定随机与介质内根部的断言。先验证缺少新 API 时测试失败，再实现随机根部、腿面附着位置、宽厚和轻微弯曲。默认基数 8，最大 128，64 个接触满额分别对应 512／8192 根。
2. `AdhesiveDisplayBudget` 在接触少时适度增加每接触绘制量，总显示预算保持有界；物理实体和网络数量保持现状。高密度采用三段几何降低绘制成本。
3. 用 `SurfaceBubbleStyle` 生成直径不超过 0.112 格的小型立体气泡。`HelperRenderer` 使用方块图集当前动画帧，避免把整张动画 PNG 画为半格大小的平面方块。保留服务器的冒泡时机、声音和结束粒子。
4. 更新中文配置说明与版本号为 0.7.3-dev。运行纯逻辑测试、构建与资源校验，再用隔离实例对 ITT／ITPR 做针对性渲染验证；原游戏存档和光影包保持原样。
5. 复用现有审查代理进行一次只读审查，处理阻断问题；记录验证范围与限制。分别保存中文发布日志、版本源码 ZIP、校验值和桌面副本，再通过 GitHub CLI 发布第二个 Pre-release。
