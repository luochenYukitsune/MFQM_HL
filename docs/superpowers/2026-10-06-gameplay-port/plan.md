# 实施计划

使用已授权的旧版对照与路线图。分工不重叠，主代理统一编译与运行。

1. 介质与物理：`block/`、`fluid/`、`gameplay/`、ModBlocks、ModFluids、ModAttachmentTypes、方块实体；完成状态碰撞、转化、下沉、呼吸、污染与装备输入。
2. 物品：`item/`、ModItems；完成方块物品、容器、食物、装备、工具与世界交互，配方、燃料、物品可用性。
3. 实体与客户端：`entity/`、`client/`、ModEntities、ModSounds；完成生物、捕获、连接、投射、视觉、HUD/覆盖和装备表现。
4. 主代理：配置、资源转换/模型与配方整合、世界生成、网络整合、入口、验证与记录。

跨模块合同：ModBlocks.byId(String) 返回 Block，entries() 提供 ID/供应器映射；ModItems.byId(String) 返回 Item。使用下划线小写现代 ID，保留显式旧 ID 映射。工具由 ModEntities 提供服务器 spawnConnector / fireLiquid / throwSinkingPotion 操作；状态接口由介质代理公布。共享目标源码在 run/1.21.11/target-sources，旧证据在 run/1.21.11/legacy-audit。

每批先建立失败验收（空注册、缺资源和关键行为），实现后执行对应检查；不以普通方块/原版怪物换皮作为全部行为替代。编译错误逐批修复，最终进行独立代码与清单审查。
