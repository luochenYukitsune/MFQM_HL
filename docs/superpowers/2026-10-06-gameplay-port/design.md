# MFQM 1.21.11 玩法移植设计

用户已要求完成上轮清单的全部补全与移植。目标保持 Minecraft 1.21.11 / NeoForge 21.11.45 / Java 21；旧版字节码、反编译及资源为行为依据。

## 内容与资源

保留全部 49 方块、13 旧流体映射、43 独立物品注册来源、16 实体角色及 metadata 变体。现代端允许把 metadata 拆为状态/物品，建立显式 ID 映射。隐藏工具和机关不作为普通创造栏装饰。恢复原贴图、动画、装备、英文/俄文及声音。

## 逻辑权威

沉陷、呼吸、伤害、负重、装备、救援、地形转化和生物行为在服务器执行。以实际身体/眼部接触区分移动和呼吸；同一 tick 只应用一次共享沉陷处理。客户端同步污染/接触状态并显示 HUD、视角、泥污和效果。原客户端物理、数字注册 ID、反射替换与未验证消息不直接搬运。

## 表现与生成

区分固体沉陷方块与流动液体，保留表壳、软化、方向、成熟、颜色等状态。生物共享适当模型，但保留独立行为。绳线、触手、气泡及动态方块采用对应表现。生成覆盖旧版核心维度生态、成簇地貌、蜂巢、蛛巢、花、肉酸坑、墓和神殿机关；按实际世界高度运行。

## 兼容范围

核心原版世界功能必须工作；第三方兼容通过可选标签和存在性检测适配，不能凭旧 mod ID 假设现代版本可用。缺失配置及已改变默认值逐项恢复/说明。注册和发布数据不依赖服务器配置，禁用开关在实际玩法路径处理。
