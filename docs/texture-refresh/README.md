# 0.6.1-dev 材质更新与拼接验证

依据维护者认可的泥土预览风格，使用 imagegen 制作材质源图，再按维护者明确允许的脚本流程适配精确尺寸、循环动画及玩家 UV 蒙层。所有修改仅位于当前工作目录；桌面的 MIT 导出副本与 GitHub 0.6.0 均未修改。

## 更新范围

共 100 张运行时 PNG：48 张方块及液体图、10 张相关物品图标、2 张相关实体图和 40 张玩家附着层。

- 泥土、泥沼、沼泽、泥炭等不同状态的表面及侧面。
- 焦油、蜂蜜、液态泥沼、Bog、Slurry 的静止与流动动画；蜂巢和相关物品、实体使用相同的新材质细节。
- 玩家泥土、黏液、焦油、蜂蜜四组附着层，每组 10 个覆盖等级。焦油和蜂蜜现在使用独立材质。

新材质由 11 张生成源图烘焙而来，其中泥土沿用维护者已认可的候选图。变体保留原色阶关系；图标保留轮廓，实体保留 UV 布局。草叶及浆果的可识别部分保留。

## 拼接与透明度

方块基本纹理为 32×32；静止液体每帧 32×32，流动液体每帧 64×64，由同一 32×32 材质重复组成，以适配原有流体 UV 尺度。

动画应用循环位移后重新匹配边缘，同材质帧的左右及上下边缘像素一致。静止和流动材质的初始区域及透明度一致；检查了所有帧的空间边缘以及末帧到首帧的变化量。保留原动画帧数、播放节奏与帧列表，蜂蜜液体保留原来 204/255 的 alpha。

玩家图像为 128×64，继续使用原来的 64×32 归一化 UV 布局。每级 alpha 蒙层均与原图等比放大后完全一致，不会因重绘增加 UV 区域或提前覆盖身体；染色与清洗渐隐仍由现有渲染代码处理。两种手臂宽度的模型布局保留。

静止与流动动画的图案会随时间变化；这不是连接纹理系统，不会消除全部可辨识的重复图案。不同材质之间也会保留边界。

## 检查结果

- `refresh_textures.py --verify`：100 张输出的哈希、尺寸、流体 alpha、播放节奏、全部动画帧边缘与循环、40 张玩家 UV 蒙层及覆盖递增检查通过。
- `gradlew.bat build`：构建成功，26 组运动行为及 35 个阻力边界样本通过。
- `verify_jar.py` 与 `verify_port.py`：通过，资源检查为 0 错误。
- 已对 JAR 内的全部 100 张贴图逐文件核对；AI 源图、原图备份与文档预览没有进入 JAR。
- 实际隔离客户端加载通过：178 项注册物品、162 项创造栏内容、49 个方块、13 个流体、16 类实体以及 40 张玩家蒙层。
- 实际客户端在复制的验证存档内建立了六组相邻方块/液体池与三个流体出口，并从两个方向渲染截图。已人工检查截图中的表面平铺及流体出口，没有明显缺失贴图或异常接缝。

当前验证包含图像检查和客户端加载、场景渲染；不是所有光照、着色器与第三方资源包组合的验收。玩家附着层的 UV/透明度已检验并实际加载，未截图逐一检查所有皮肤和装备组合。

`sources/` 保留生成源图，`inputs.json` 给出相对路径；`manifest.json` 记录全部运行时贴图、哈希与尺寸；`originals.zip` 保存修改前的原图及动画元数据。反复烘焙始终读取原始备份，不会把已重绘的图作为下次输入。

安装 Python 3.11+、Pillow 和 NumPy 后，在项目目录运行：

```powershell
python tools/refresh_textures.py --bake
python tools/refresh_textures.py --verify
python tools/smoke_client_port.py
```

本地产物：`build/libs/MFQM-neoforge-1.21.11-0.6.1-dev.jar`。这些新材质随项目采用 MIT 许可；原作者及来源声明继续保留。
