# 胶水、粘鼠板与挣扎（0.7.3-dev 预发布版）

适用 Minecraft 1.21.11 / NeoForge 21.11.45 / Java 21。本预发布版包含白色半透明胶水、可重复使用的粘鼠板，以及腿脚与黏性介质之间的膜和拉丝。

当前为 0.7.3-dev 预发布版，中文变更见 [0.7.3 更新日志](../release-notes-0.7.3.zh-CN.md)。安装文件为 `MFQM-neoforge-1.21.11-0.7.3-dev.jar`，联机建议两端一起更新，同步版本为 7。本版扩大黏丝显示可调上限、增强初次接触密度、加入稳定随机外观并缩小表面气泡；保留独立发布的 [0.7.2-dev](../release-notes-0.7.2.zh-CN.md) 高位黏丝、透明度和 ITT／ITPR 池面修复。

## 获取与使用

- 胶水桶：黏液球、骨粉、水桶无序合成。投入的水桶成为胶水桶，不额外返还空桶。
- 粘鼠板：上排三张纸、下排三块木板，合成三张空板。放在有支撑的地面，用胶水桶右键补胶；生存模式返还一个空桶。
- 创造栏相邻提供 **粘鼠板（已涂胶）** 和 **粘鼠板底板（未涂胶）**。已涂胶版带满格胶层，直接放下即可困住目标；未涂胶版仅为可重复补胶的底板，名称和提示明确区分。
- 板子不区分放置者，玩家及指定中小型生物都会受困。涂层在使用、挣扎中耗尽，底板保留；回收和重放保留剩余涂层。
- 同一高度、四边相邻的板自动拼成大板，内部木边隐藏，胶面接缝和四角连通，整片外缘保留木边。拆掉邻板会恢复边框；对角或不同高度不连接。空板也能拼接，但各格胶量、补胶、回收与受困独立，不会自动获得邻板的胶层。旧板会在所在区块加载完成后自动刷新连接。
- 主世界湿润森林、沼泽的新区块可以生成浅、深胶水池；本模组沙漠墓增加少量粘鼠板机关和材料奖励。

## 脱困

默认 **F** 每按一次进行一次挣扎，连续按住不会自动连发，动作有冷却。浅层抬腿拔脚，深层扭身、手臂撑拉；第一人称有手部反馈和可关闭的轻微镜头变化。移动和跳跃也参与挣扎。

黏连期间可以实际小范围走动、跑动和短跳；范围外的迈步由绷紧的黏丝限制，挣扎减弱黏力并扩大活动范围。跳跃按下触发有限短跳，持续按住不会连续上浮。黏度通过实际运动约束实现，不修改移动速度属性来缩放 FOV；保留玩家原有视角设置及原版疾跑、拉弓效果。

完整黏力时的默认活动半径：胶水 1.2 格、蜂蜜与黏液 1 格、焦油 0.8 格、黏稠泥潭 0.6 格、粘鼠板 0.7 格。黏丝接近边缘才开始回拉，服务器可独立调整活动半径。断裂距离至少保留活动半径加 0.4 格，避免正常转身或短跳立即挣断。

各类残留按实际浸入高度从脚到头递增，共十级。0.7.5-inside 起，胶水、泥沙、黏液、焦油和蜂蜜等采用贴合皮肤与实际衣物像素的薄膜，默认微起伏不超过 0.018 模型像素。3D Skin Layers 的凹凸网格直接覆膜，不再按最大尺寸整体撑出方壳；透明衣物区域保持空缺。第一人称手臂和 FirstPersonModel 的身体沿用当前部件的姿势与可见性。只有腿部新近接触时不会新增上半身污渍，历史残留仍需消退或水洗。可关闭“贴肤薄膜细节（全部材质）”，16 格外自动取消微起伏。

0.6.7-dev 将所有残留的默认凸起减半，并减少外层安全间隙；隐藏的皮肤外层不再把覆盖撑离基础皮肤。实际立体皮肤继续按部件最大尺寸避让，透明洞暂未逐像素贴面。

胶水中静止不会继续下陷；反复挣扎削弱黏连，但达到阈值后会加深下陷。停止挣扎停止继续下陷，仍需向边缘挪动或接受救援。深池有窒息危险。粘鼠板不会使角色下陷，饱食正常时持续按 F 约 20 秒可削弱到能挪出；饥饿时效率下降，仍能挣扎。每次接受的专用挣扎增加少量饥饿消耗。

焦油、蜂蜜、胶水、黏液及涂胶粘鼠板产生黏丝；泥潭、沙类和黏土等非黏性介质不再拉丝，仍保留下陷和挣扎。竖向断裂距离默认胶水 4 格、蜂蜜/黏液 2.7 格、焦油/板 2 格，水平范围独立。移动接触新位置时新增黏丝（同格内也生效），最多 64 条，满额让最旧的依次断开；静止不会无限补丝。根部放在实际介质内部，液面变化时校正，介质消失时移除。水仅清洗残留，不会洗断有效黏丝。

## 留靴与救援

在胶水或涂胶板上奋力拔脚、挣断时，靴子可能留在介质中；正常站立不会随机掉靴。原版靴子和涉水靴均可发生，留靴保留附魔、耐久和名称。靠近空手右键取回，长棍或绳索可以辅助够取，移除介质也会释放。满背包不会吞掉靴子。

绳索必须手持才能使用。首次右键挂接；挂接后按住右键收绳，潜行右键放绳，松开停止。**R** 收绳、**X** 释放的辅助键同样要求手持。**F** 始终用于挣扎。

## 配置与验收

服务端配置包括黏连开关、各介质断裂距离、留靴概率和胶水池／遗迹板生成参数。客户端可以分别关闭挣扎动作、挣扎镜头和黏丝显示。关闭飞行的创造玩家默认也受束缚和下陷，但免受伤害；服务器可通过 `creativeGroundPhysics` 关闭创造地面物理。旁观及正在飞行的玩家始终免疫。

在模组列表中打开 MFQM 的中文配置，进入“客户端显示 → 画面显示”，调整全局覆盖透明强度、胶层微起伏及每个角色黏丝显示上限；下方提供各材质单独设置。透明与微起伏的全局值和材质值相乘，黏丝取两个上限中的较小值。设为 0 可隐藏覆盖、取消起伏或隐藏黏丝；这些显示选项不改变物理和水洗。旧 `glueCoating3d` 键保留兼容，控制全部材质的薄膜细节。

“每个接触的独立黏丝数量”是每组的基础密度，默认 8，可调 1～128；“黏丝束显示上限”仍按接触组计数，默认 64，因此附近接触满额时默认最多约 512 根，最高设置最多 8192 根。初次接触较少时，每组显示量最多增加四倍，总量仍受预算约束；移动后接触逐渐增加。每根是独立、完整、无分叉的胶带，根部仍在介质内。实际数量受接触、显示组数和距离淡出限制，8192 是允许上限，不代表静止时固定画满。旧配置无需重置；很高的数值会明显增加客户端几何开销，建议从默认值逐步调整，服务器实体数量与黏力不变。

0.7.3-dev 分别随机根部散布、腿面附着位置、宽度、截面厚度和微小弯曲，减少整齐扇形与重复宽度。随机量按连接身份和黏丝序号固定，调整密度不会重排已有根部，也不会逐帧闪跳。高密度采用较少的几何分段，保留平顺轮廓和实体厚度。介质表面的泡泡改为小型立体凸起，直径不超过约 0.112 格，使用方块图集中的当前动画帧；“表面气泡”显示开关、冒泡声音和少量破裂粒子仍保留。

0.7.2-dev 让约四分之一的黏丝连接到实际腿模型的小腿中部，其余主要保持脚踝高度。随机高度按连接身份固定，跟随走路与挣扎姿势，不逐帧跳动；介质根部仍完整位于液体内部。高位连接不扩大身体污渍的覆盖范围，胶膜与身体覆盖仍按接触深度处理。

胶水身体覆盖强度小幅提高 20%，保留半透明与皮肤细节。蜂蜜、焦油、黏液的身上覆盖、黏丝与池面更半透明，颜色不变；原有全局及单材质覆盖设置继续生效。光影版也保留透明度渐退与平面覆盖模式，详情见 [光影兼容说明](shader-compatibility.md)。

0.6.6-dev 同步协议为 6，客户端和服务端必须一起更新。旧泥潭黏丝距离/活动半径配置项为兼容旧文件保留，已不再作用于非黏性介质。

0.6.7-dev 继承协议 6，修复第一人称脚环与实际身体偏移的对齐。黏丝外观变为脚边短密束，每接触五条细丝；水平 0.45～0.65 格、竖向 0.9～1.15 格逐渐淡出，保留原活动范围和物理断裂阈值。中文“黏丝束显示上限”可减轻显示密度。

0.6.8-dev 延续协议 6。每脚仅保留一层半透明胶膜，浅层停在鞋底与脚踝，深层才伸向小腿。胶膜是有内外壁与薄边缘的立体薄壳，厚度 0.003 格；每个接触只有一根连续黏丝，是封闭六边截面细管，没有分叉；胶水及涂胶板的黏丝半径加倍，随拉伸收细、松弛弯曲，并在断裂时短暂回缩。所有有黏丝的介质使用对应颜色；身体其他部位继续沿用原有逐像素凸起及显示强度设置。胶水池仍使用现有流体表面。近处模型更精细，密集场景可调低“黏丝束显示上限”。

0.6.9-dev 将连续黏丝改为带实体厚度的扁胶带截面，胶水及涂胶板主宽度比上一版增加 50%；减少松垂和回缩时的弯垂，脚部端点朝向各自根部。显示根部依据原生流体四个边角的最低高度收进液面下，整个端面同时避开方块侧边和底部；液层过薄时缩小根部，无法容纳时隐藏。保留无分叉、贴脚薄壳、第一人称兼容、活动范围及服务端束缚规则。

0.6.10-dev 默认每接触显示 8 根独立黏丝，并将身体端点稳定随机抬高到胶膜高度的 25%～75%。浅层仍在鞋底、脚踝附近，深层才到小腿下部；高度沿原生腿部姿势变化，不会每帧重新随机，也不延伸到上半身。所有有黏丝的介质共用此改进。根部完整浸没、厚度、无分叉及原有玩法保持；静止不会无限补丝，每脚仍只有一层胶膜。

0.6.11-dev 新增粘鼠板拼接状态，同步协议升为 7，客户端和服务端需同时更新为同版。拼接只改变外观，单板物品模型、胶层消耗、碰撞高度及救援规则沿用此前实现。
